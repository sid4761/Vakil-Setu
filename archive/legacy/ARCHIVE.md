# Legacy application archive

This directory preserves the earlier Vite/React frontend and Express/MongoDB backend, including their manifests, lockfiles and environment templates. It is historical reference, outside the current Bun workspaces, and is not used by the current Next.js application.

The original legacy README is retained as `README.md`; its setup and feature claims apply to that version. Use the repository root README for the current application. No actual environment files, credentials, databases, dependencies or production data were copied. Legacy code was not executed, migrated, audited for all vulnerabilities or certified for deployment by this archival task. Scraping and destructive maintenance scripts are historical source and must be reviewed before any execution.

The original gateway integration is examined in [the legacy AI audit](../../docs/legacy-ai-audit.md). Archived AI/payment/emergency code does not establish those capabilities in the current MVP.
